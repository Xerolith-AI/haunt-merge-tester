# Haunt Merge — Web Tester

**No paywalls.** Free static Phaser build for playtesters.

## Play

GitHub Pages: https://xerolith-ai.github.io/haunt-merge-tester/

Or locally:

```bash
python3 -m http.server 8080
# open http://127.0.0.1:8080/
```

Needs network once for Phaser CDN (`cdn.jsdelivr.net`). Best in phone portrait.

See `TESTER_README.md` for controls.
